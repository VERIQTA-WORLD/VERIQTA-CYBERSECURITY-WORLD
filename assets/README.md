# Cybersecurity World Visual Assets

Covers and discipline visuals support the VERIQTA Cybersecurity World collection.

## Visual formats

PNG images and editable SVG sources use 1080 by 1350 portrait canvases with Arial typography. Each discipline has a corresponding cover. Shared resource, publication release, and evidence-to-decision visuals support navigation and learning.

- [Cybersecurity World cover](cybersecurity-world-cover.png).
- [Evidence to decision](evidence-to-decision.png).
- [Shared resources](shared-resources.png).
- [Publication releases](publication-releases.png).

The artwork uses a VERIQTA text heading and watermark. The shield is an original cybersecurity illustration, not the official VERIQTA emblem.
